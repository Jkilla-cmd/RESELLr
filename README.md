RESELLr-1

RESELLr is a private, offline-first web app for resellers to track inventory, sales, and profit — without relying on marketplace dashboards.

It’s built for resellers who want clarity, not clutter.

⸻

✨ What RESELLr Is

RESELLr helps you answer:
	•	How much money is tied up in inventory?
	•	Am I actually profitable?
	•	What sells best — cards, comics, or other?
	•	Where am I losing money to fees or shipping?

It works alongside platforms like Mercari, eBay, and Whatnot — but your data stays with you.

⸻

⚡ Quick Start (2 Minutes)
	1.	Open the app in your browser
	2.	Set a passcode when prompted
	3.	Add inventory or import a CSV
	4.	Mark items as sold
	5.	Track profit automatically

That’s it.
Inventory

Items you currently own and plan to sell.

Sold Items

Items that have sold. Profit is calculated automatically.

Type

Each item can be tagged as:
	•	Comic
	•	Card
	•	Other

This enables better reporting and filtering.

⸻

🧾 How to Use RESELLr

1️⃣ Login & Security
	•	RESELLr uses a local passcode
	•	No accounts
	•	No cloud
	•	No servers

⚠️ If you forget your passcode, clearing browser storage will reset the app and delete local data.

⸻

2️⃣ Add Inventory (Manual)

Go to Inventory → Add Item and enter:
	•	Date acquired
	•	Item name
	•	Type (Comic / Card / Other)
	•	Platform (Mercari, eBay, etc.)
	•	Cost
	•	List price
	•	Quantity
	•	Notes (optional)

⸻

3️⃣ Import Inventory (CSV)

Go to Import / Export → Inventory Import

Accepted type values:
	•	Comic
	•	Card
	•	Other
(case-insensitive)

⸻

4️⃣ Mark Items as Sold

From Inventory:
	•	Click Sold on an item
	•	It moves automatically to Sold Items

Or manually add sold items from the Sold section.

⸻

5️⃣ Import Sold Items (CSV)

Go to Import / Export → Sold Import
6️⃣ Sold Summary & Profit

The Sold section shows:
	•	Total sales
	•	Net profit
	•	Profit per item
	•	Color-coded profit:
	•	🟢 Green = profit
	•	🔴 Red = loss

Filters available:
	•	Date
	•	Type (Comic / Card / Other)

⸻

7️⃣ Export Your Data

From Import / Export:
	•	Export Inventory to CSV
	•	Export Sold items to CSV

Perfect for:
	•	Backups
	•	Taxes
	•	Spreadsheets
	•	Long-term records

⸻

🔒 Privacy & Data Storage
	•	All data is stored locally in your browser
	•	No analytics
	•	No tracking
	•	No external servers

💡 Export regularly if you want backups.

⸻

📱 Progressive Web App (PWA)

RESELLr can be installed like a native app:
	•	Works offline
	•	Full-screen app experience
	•	Desktop & mobile friendly
